# AuthApp: Angular Login & Register System

Modern authentication demo built with Angular (standalone components, signals, reactive forms).

**[Live Demo](https://BassantEzzat.github.io/auth-app/)**

## Features

- Register and login with full form validation (name, email, strong password, confirmation, duplicate email check)
- Passwords salted and hashed (SHA-256) with the Web Crypto API
- Persistent session and route guards
- Responsive UI with animations and page transitions

## Run locally

```bash
git clone https://github.com/YOUR_USERNAME/auth-app.git
cd auth-app
npm install
ng serve
```

> Frontend-only demo: data is stored in the browser's `localStorage`.
